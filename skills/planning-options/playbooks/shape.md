# Diverging, and the shape an option has to take

## Divergence Prompts

Use when the option set is really one idea in three costumes.

| Prompt | Produces |
|--------|----------|
| What if we had one day? | The minimum viable version, often the winner |
| What if we could not touch <the obvious component>? | Approaches routed around the assumed center |
| What would we do if this had to be reversible in an hour? | Flag-gated, additive, or shadow approaches |
| What does buying instead of building look like? | Vendor and off-the-shelf options |
| What if the volume were 100×? | Approaches that survive growth |
| Who has solved this already, and what did they do? | Prior art the team is reinventing |
| What if we solved the adjacent problem instead? | Reframes that dissolve the original problem |

## Option Shape

```
### O-2: <name>
- Mechanism: <how it actually works, two lines>
- Cost: <effort range, new dependencies, ongoing burden>
- Forecloses: <what becomes hard or impossible afterward>
- Fails by: <the realistic failure mode, not the worst case>
- Reversal: <what undoing it takes> — hours | days | weeks | practically never
- Evidence: <one tag per claim — [verified: pointer] | [assumed] | [unknown]>
```
